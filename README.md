# Dindigul Venu Biriyani Hotel

A rich, interactive landing page and web showcase for Dindigul Venu Biriyani Hotel.

## Features
- **Hero & Intro Showcase**: Interactive video presentation and header canvas animation
- **Menu Highlights**: Signature Dindigul dum biryani classics and accompaniments
- **Social & Reviews**: Instagram reel/media showcases and Google guest reviews

## Running Locally
To run locally, you can serve the directory using Python's built-in HTTP server:

```bash
python -m http.server 8000
```

Then visit [http://localhost:8000](http://localhost:8000) in your browser.
